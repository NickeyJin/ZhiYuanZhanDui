# 机械臂操作卡（板子里现在烧的是这一版）

固件：`build\direct\MyFirstCar.elf`（麦轮 + 手柄 + 机械臂三合一）
上次烧录：2026-10-19 01:22，验证过 `ps2_ok=1`、四路松劲、状态干净。

---

## 一、上车三步

1. **上电**。LED 快闪 3 下 = 机械臂初始化完了，**这时候四路是松劲的**（舵机不使劲，你用手能掰动）。
2. **摆位置**。把大臂/小臂/爪子用手摆到你想要的起始姿势。
3. **按 SELECT + START**。听到/看到闪 2 下 = 四路通电，开始保持住。之后松手它也不掉。

> 为什么不在上电时直接通电：舵机一通电就会去追记忆里的脉宽，
> 你的手要是还按在臂上，会被硬拧一下。所以这一步交给你确认。

想再松劲（比如要用手复位、或者要拆装）：**再按一次 SELECT + START**（闪 1 下）。

## 二、点动（不按 R2 的时候）

| 按键 | 动作 | 行程 |
|---|---|---|
| ↑ / ↓ | 肩（大臂根） | 只有 ~28°（1192~1504us），按几下就到头 |
| △ / × | 肘（大臂与小臂之间） | ~143°，主要靠它 |
| ← / → | 腕（爪口朝上还是朝下） | ~158° |
| □ / ○ | 爪 张开 / 合上 | ~68° |
| 按住 L1 | 速度 1/3，调精确位置用 | |
| 按住 R1 | 速度 3 倍 | |
| START | 整车急停：底盘停、机械臂也停手（松手恢复） | |

所有运动都是"按住就一直走、松手就停在那"，不会自己飘。

**按了方向反了怎么办**（比如按 ↑ 大臂往下走）：
按住 **R2 + L1**，再按一下那个键，就把那一路的方向对调了：

- `R2 + L1 + ↑` → 肩反向
- `R2 + L1 + △` → 肘反向
- `R2 + L1 + ←` → 腕反向
- `R2 + L1 + □` → 爪反向（张开/合上互换）

## 三、录制 → 回放（自动拾取动作）

R2 是录制键。

| 操作 | 作用 |
|---|---|
| `R2 + △` | 开始录制（会清空之前录的，闪 3 下）。再按一次 = 结束录制（闪 2 下） |
| `R2 + ×` | **记一个点**：把当前四路脉宽 + 距上一个点的时间存进数组（闪 1 下） |
| `R2 + ○` | 现场试回放 |
| `L2 + R2 + SELECT` | 正式回放（你指定的那个组合） |

录的时候 LED 是 100ms 快闪，回放时 LED 常亮。最多 32 个点。

**录一个"抓方块"的动作大概这样**：

1. 点动把爪子开到最大（□ 按住）
2. `R2 + △` 开始录
3. `R2 + ×` 记第 0 点（张开、在起点）
4. 点动走过去、下降，到方块位置 → `R2 + ×` 记第 1 点
5. 按 ○ 合爪，等它夹住 → `R2 + ×` 记第 2 点（**"什么时候合爪"就是这个点之前那一下**）
6. 抬起来 → `R2 + ×` 记第 3 点
7. 走到投放点 → `R2 + ×` 记第 4 点
8. 按 □ 张开 → `R2 + ×` 记第 5 点
9. `R2 + △` 结束录制
10. `L2 + R2 + SELECT` 看它自己跑一遍

时间间隔是按你按 `R2 + ×` 的真实间隔记的，所以**录的时候动作节奏要和实际希望的一致**（慢了回放就慢）。

阵列在 RAM 里，掉电就没。录好了告诉我，我帮你写死进代码。

## 四、现场调限位（按住 R2 再按方向键）

2 号舵机（肘）的软限位可以现场改，不用重烧：

| 组合 | 作用 |
|---|---|
| `R2 + ↑` / `R2 + ↓` | 上限 +20 / −20 µs |
| `R2 + ←` / `R2 + →` | 下限 −20 / +20 µs |
| `R2 + START` | 恢复默认值 |

硬边界 500~2500µs（舵机自己的电气范围），改不出去。每改一次闪 2 下。

> 改的值只在 RAM 里，断电回默认。定下来告诉我，我写进 `arm.h`。

## 五、出问题看这里

| 现象 | 原因 |
|---|---|
| 按方向键，舵机完全不动、能用手掰 | 还没按 SELECT+START 通电 |
| 舵机嗡嗡响、发烫、不动 | 顶到机械端了。软限位已经内收，还响就说明是结构卡住（或该舵机行程不够） |
| 录制时按 `R2 + ×` 没反应 | 没先按 `R2 + △` 开始录制 |
| 回放闪 3 下不动 | 数组里没点 |
| 整车一动就重启 | 舵机电源不够。四路 MG995/SG90 必须独立 5V + 470uF + 与 MCU 共地 |
