## 0. 先给三个问题的答案

### ① 要不要做逆解？——**不做 MCU 实时逆解，只做"离线算一次 + 预设位姿"**

理由（按重要性排）：

1. **没有角度反馈**。车的电机都没编码器，舵机更不会回读角度。舵机 µs 和真实角度的对应关系只能靠标定，标定一次之后就是固定映射——那在 MCU 里实时算逆解毫无意义，算出来的角度也没法验证。
2. **只需要 3~4 个固定姿态**。比赛里的动作就这些：收纳折叠、下探抓地、举高、投放到车厢。设成预设位姿，一键到位，比逆解可靠得多。
3. **STM32F103 没有硬件浮点**，20ms 节拍里跑 sin/cos/atan2 是软件浮点，慢且占 flash，收益为零。

**但是**"逆解"这件事本身有用——用在**算预设值**上：如果想让夹爪落到某个精确坐标（比如"地面往后 80mm、高 0mm"），手算两连杆角度很容易算错，所以我写了个离线小工具：

```powershell
python build\tools\arm_ik.py 90 0      # 末端要去 (水平90mm, 高度0mm)
```

它输出两个舵机的 µs，你抄进 `Core/Inc/arm.h` 的预设位姿宏里就行。**这次只算不收**，省掉 MCU 里的复杂度。

### ② 怎么操控？——**六键点动 + 一键预设 + R1+SELECT 一键折叠**（已经写进固件）

| 手柄 | 作用 | 说明 |
|---|---|---|
| 左摇杆 | 底盘平移 | 已有 |
| 右摇杆 | 底盘自转 | 已有 |
| **↑ / ↓** | 大臂 上 / 下 | `SIGN_ARM_FWD` 方向反了就改 `-1` |
| **△ / ×** | 小臂 内收 / 外伸 | `SIGN_ELBOW_IN` |
| **← / →** | 夹爪 张开 / 闭合 | `SIGN_GRIP_OPEN` |
| **SELECT**（单击） | 一键流程：合爪 → 到投放位 → 张爪 → 归位 | 再按一次取消，停在原地 |
| **R1 + SELECT**（新增） | **一键折叠到收纳位** | 收车、赛前整备用 |
| START | 急停（全停，臂原地不动） | 已有 |
| L1 | 底盘半速 | 已有，别拿去给臂用 |

点动是"按住一直走，松手立刻停"（每 20ms 推一小步，不过冲），适合微调。

### ③ 多长、能不能折进 210mm？——**能，但必须"平躺折叠"，不能做"立塔"**

规则原文（手册第 6–7 页）：

| 约束 | 数值 |
|---|---|
| **初始尺寸**（每局开始那一刻） | 长×宽 **≤ 290×195mm**，高 **≤ 210mm** |
| 任意时刻上限（二选一） | 长×宽×高 **≤ 445×400×450mm**，或装进 **φ550mm 球体**（平面距球心 180mm） |
| 重量 | **≤ 2.0kg** |
| 强度检测 | 从 **150~200mm** 高自由落体，不能掉零件 |
| 成本（新生组） | 不推荐超过 **400 元** |

**关键结论：展开时非常宽松（445×400×450 比底盘大得多），真正的硬约束只有"开局 210mm 高"。**
所以机械臂的设计目标只有一个：**折叠后整机高度 ≤ 210mm，且不伸出底盘 290×195 的轮廓**。

推荐的折叠几何（明天装的时候按这个思路）：

- 大臂舵机枢轴**低装**：离地 **90~110mm**，装车体后部或中部；
- **L1（大臂）≈ 90~100mm，L2（小臂）≈ 80~90mm**（指舵机轴心到下一关节轴心的距离）；
- 折叠姿态：大臂沿车身水平向后倒、小臂回折贴住大臂、夹爪合上 → 高度只增加 ~30mm，远低于 210；
- 抓地：枢轴 100mm 高、总长 190mm → 最低能探到地面并伸到车头前 ~80mm；
- **不要做成"竖直塔式"**：臂立起来高度立刻超 210，而且重心高、跌落测试容易散。

> 验证方法：装好后用卷尺量"车放平、臂折到底"的最高点，写进下面的表。**必须留 10~15mm 余量**（规则卡临界会判超）。

## 1. 目标动作是什么（决定臂长和夹爪尺寸）

| 道具 | 说明 | 尺寸 |
|---|---|---|
| 能量单元（白方块） | 全场 18 个，放在地面胶带标记处 | 白立方体，约 30mm 量级（现场量） |
| 能量核心（黄方块） | 全场 5 个，**其中 2 个在台阶下的洞穴里** | 同上，约 11.29g |
| 洞穴 | d1、e8 台阶下，**向外开口 70×70×50mm** | 夹爪要塞得进去 |

所以夹爪有两条硬指标：

1. **能夹起 30mm 左右的方块**（开口 ~45~60mm，指尖带硅胶/热缩管防滑）；
2. **整体能塞进 70×70×50 的洞**：夹爪总宽 < 65mm、总高 < 45mm，且要能从水平方向伸进去抓。
   → 夹爪结构越扁越好，别做成"大手掌"。

## 2. 舵机与供电（**今天最容易翻车的地方，放第一位**）

料表里现有：**MG995 ×2（180°，铁+铜齿轮）、SG90 ×4**。分配建议：

| 关节 | 舵机 | 理由 |
|---|---|---|
| 大臂 | **MG995** | 要扛小臂+夹爪+方块，扭矩余量最大 |
| 小臂 | **MG995** | 同上，且离末端更近、更省 |
| 夹爪 | **SG90** | 只需夹 11g 的方块，SG90 富余很多 |

扭矩核算（按标称 60% 估可用扭矩，因为 5V 供电有压降）：

- MG995 @5V ≈ 9kg·cm ×60% ≈ **5.4kg·cm**
- 大臂最坏情况（水平伸直）：小臂总成+方块约 90g × 90mm ≈ 0.81kg·cm；大臂自身 80g × 45mm ≈ 0.36kg·cm → **合计 ~1.2kg·cm**，余量 4 倍以上 ✓
- SG90 @5V ≈ 1.8kg·cm ×60% ≈ **1.1kg·cm**；指尖力臂 15mm → 夹持力约 **7N**，夹 11g 方块所需不到 0.2N ✓

**供电（必做，否则明天必炸）**：

```
电池 → DC-DC 5V 模块 → 舵机 VCC（三路并联）
                     ↘ 470µF 电解电容（贴着舵机端）
所有 GND 必须和 STM32 共地 ← 这一条忘了会乱抖/丢帧/重启
信号线 PB6/PB7/PB8 直连舵机信号脚（不要串电阻）
```

- **不要把三个舵机挂在开发板的 5V 排针上**：MG995 堵转电流 1A+，会把 MCU 拉复位。
- 电源线和信号线分开走，别捆在一起。
- 上电顺序：先给舵机供电，再上电 MCU（或同时）；**不要热插拔舵机线**（容易打坏 IO）。

## 3. 明天 90 分钟流程

### 第 1 步：验证按键组 2（5 分钟，**必须先做**）

之前读数里 `t_btn2_or = 0` —— **△○□× / L1 L2 R1 R2 这 8 个键从来没被测到过**（可能只是没按，也可能映射是错的）。而小臂点动用的是 △/×，一键折叠用的是 R1。

做法：烧 `build\ps2test\MyFirstCar.elf`（如果还在里面就不用烧），抓着手柄把 △○□×、L1 L2 R1 R2 各按一遍，然后我读 `t_btn2_or`，应该变成非 0。**如果读出来还是 0，说明按键映射要改，先别装臂。**

### 第 2 步：单个舵机标定（20 分钟）

一次只接**一个**舵机，另两个拔掉：

1. 烧正常固件（`build\tools\direct_build.ps1` 不加参数 → `build\direct\MyFirstCar.elf`），用 `flash.ps1` 烧进去；
2. 按 ↑/↓（或 △/×、←/→）看它往哪转，**转反了就把 `arm.h` 里对应的 `SIGN_*` 改成 `(-1)`**；
3. 慢慢点动到两个机械极限位置，**读回当前 µs**（用 `ps2test_read.ps1` 读不到 arm 的变量——临时办法：在 `app.c` 里把 `arm_get_now()` 的结果塞进 `.persist` 的 `t_axis_min/max` 槽位，或者直接看角度估），记下 `US_ARM_MIN/MAX`、`US_ELBOW_MIN/MAX`；
   - **软限位宁紧勿松**：机械上还能再走 20µs 也留出余量，别让舵机顶死（顶死 = 堵转 = 烧舵机 + 电流拉崩供电）；
4. 有多个舵机共用一套限位，一个一个来，别同时上电。

### 第 3 步：装配 + 量折叠姿态（20 分钟）

> **装舵机臂（摇臂）的时候就把"折叠位"对到舵机中位附近**：这样 `US_*_FOLD ≈ 1500`，
> 上电时臂不会猛冲到中位。**先对好摇臂角度再拧螺丝，别通电后再掰**——掰不动会烧齿轮。

1. 按第 0 节的平躺折叠方案装好；
2. 手柄点动到**最低最扁**的位置（大臂倒平、小臂回折贴住、夹爪合上）；
3. 读三个 µs → 填进 `arm.h`：
   ```c
   #define US_ARM_FOLD      ____
   #define US_ELBOW_FOLD    ____
   #define US_GRIP_FOLD     ____
   ```
4. 卷尺量整机（折叠态）：长 ___ × 宽 ___ × 高 ___，**必须 ≤ 290×195×210**，记录在下表；
5. 称重：整车 ≤ 2.0kg。

### 第 4 步：填一键流程的三个姿态（15 分钟）

`arm.h` 里这 4 个数决定 SELECT 一键流程：

```c
#define MACRO_BOX_ARM     ____   /* 投放时大臂 */
#define MACRO_BOX_ELBOW   ____   /* 投放时小臂 */
#define MACRO_HOME_ARM    ____   /* 归位时大臂（建议 = US_ARM_FOLD 或略微抬起）*/
#define MACRO_HOME_ELBOW  ____   /* 归位时小臂 */
```

现场点动到"能把方块放进车厢/箱子"的位置，读三个 µs，填进去。**归位位建议就用折叠位**，这样一键流程跑完车就能直接走，不会挂着臂过障碍。

### 第 5 步：实测动作验收（20 分钟）

| 验收项 | 通过标准 |
|---|---|
| 折叠 | R1+SELECT 一键折到底，最高点 ≤ 200mm（留余量） |
| 抓地 | 能从地面夹起 30mm 方块，夹住后举到 150mm 不掉 |
| 进洞 | 夹爪能水平伸进 70×70×50 的洞（用纸箱开个洞模拟）并把方块夹出来 |
| 保持 | 举着方块开底盘走一圈（前进+横移+自转各一次），方块不掉、臂不软 |
| 一键流程 | SELECT 一次跑完 合爪→投放→张爪→归位，全程 ≤ 6 秒 |
| 急停 | 流程中按 START，臂立刻停住、不回弹、不掉方块 |
| 供电 | 三个舵机同时动，MCU 不重启（灯不闪断）、PS2 不掉线 |

> 舵机同时启动电流大：如果 MCU 重启/PS2 掉线，就是供电问题，加电容、换更粗的线、或者让三个舵机错开 50ms 启动。

**上电姿势的坑**：`ARM_HOME_IS_FOLD` 现在是 **1**，意思是开机就把臂摆到 `US_ARM_FOLD`。现在 `US_*_FOLD` 还是占位值 1500（=中位），**第 3 步量完必须立刻填真值**，否则开机时如果臂已经折着，舵机会把它从中位掰过去，可能顶死。

## 6. 风险与兜底

| 风险 | 兜底 |
|---|---|
| 按键组 2 映射是错的 → 小臂/折叠用不了 | 第 1 步先验证；错了就先只用大臂+夹爪（↑↓←→ 属于组 1，已验证） |

| 没时间做完整版 | 优先保证：折叠尺寸 ✓ → 抓地面方块 ✓ → 一键流程 ✓；进洞放最后 |
