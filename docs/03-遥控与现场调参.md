# 03 遥控与现场调参

## 微秒级时基（DWT）

### 功能描述

`dwt_delay.c` 用 Cortex-M3 内核的 DWT 周期计数器做 `delay_us()`：

```c
CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk;
DWT->CYCCNT = 0;
DWT->CTRL |= DWT_CTRL_CYCCNTENA_Msk;
/* delay_us（us）: ticks = us * （SystemCoreClock / 1000000），忙等 */
```

### 开发历程

`HAL_Delay()` 只有 1ms 分辨率，并不够。
而且，当时电控课教了这个，我想了想，也就尝试着学习了一下。
反正是基础组件，没什么好说的。

## 按键分工（人机交互）

### 功能描述

一套手柄、两个被控对象（底盘 + 机械臂），按键分工如下：

| 按键 | 功能 |
|---|---|
| 左摇杆（只取主导轴） | 前后 / 左右平移，四个方向各占 90°，不斜走 |
| 右摇杆左右 | 原地自转 |
| 按住 L1 | 速度全减半（精细走位） |
| 按住 SELECT + ↑/↓ | 前后配平旋钮（见下） |
| 按住 SELECT + ←/→ | 总速度旋钮 |
| 按住 SELECT + L2/L1 + ←/→ | 单轮补偿：左前 / 左后 |
| 按住 SELECT + R2/R1 + ←/→ | 单轮补偿：右前 / 右后 |
| START | 急停（底盘停 + 机械臂松劲，灯慢闪） |
| SELECT + START | 机械臂四路通电 / 松劲 |
| ↑/↓、←/→、△/×、□/○、L1、R1 | 机械臂点动（见 04 篇） |
| R2 + R1 | 放块宏（见 04 篇） |

### 开发历程

- 一开始，左摇杆是可以任意方向平移与移动的，本来是打算这么设计的。但是呢，后来发现，如果这样的话，很难做测试，因为手歪了一点车就歪了。因此，就改成了现在这样，左摇杆只有4个输出，前后左右。
- 右摇杆倒是一直非常稳定的自转
- 上面的这些按钮的作用，的确是我一点点试验出来的我比较舒服的键位格式

## 现场调参旋钮（`.persist` 段）

### 功能描述

调参值放在链接脚本专门划的 `.persist` 段（RAM，NOLOAD）： **复位不清零，只有断电才丢**。
这正好匹配“赛场上反复试、懒得每次重烧”的用法。

| 变量 | 含义 | 范围 | 默认（现场定稿） |
|---|---|---|---|
| `t_speed_scale` | 总速度倍率（千分比） | 100 ~ 1250 | 960 |
| `t_wheel_delta[4]` | 单轮补偿（千分比，FL/FR/RL/RR） | ±600 | +80 / +40 / +200 / +140 |
| `t_trim_delta` | 前后配平 | ±300 | +30 |
| `t_fw_id` | 固件指纹 `0x4D454331`（“MEC1”） | — | 读到才说明烧的是开车固件 |

配套的结构体版本号 `TUNE_MAGIC = 0x54554E32`（“TNU2”）：变量增删时换掉它，上次留下的脏数据自动作废。

调完以后不必强记：`read_vars.ps1` 读回来，抄进 `tune.c` 的 `defaults_init()`，重编译烧录即固化。

### 开发历程

- 10-17 第一版只有 `SELECT + ↑/↓` 前后配平（每 250ms 一格、范围 ±300、掉电保存）。
- 10-19  03:00 细化成“四轮各自配速按键”，于是有 `SELECT + L2/L1/R2/R1 + ←/→` 的映射（左边两个键对左边两个轮子，位置一致）
- 现场发现“每一档速度对应的最佳配比不一样”，所以这组旋钮**在正式版里保留**，不是临时调试开关。

## LED小灯

### 功能描述

因为没有TTL串口，对我来说，唯一能看到的反馈通道是 PC13 连着的小灯。
所以，只能把LED小灯当作状态机的一部分表示一下（比如说：闪n下，就是第n个轮子。常亮——就是一切正常等等）

### 开发历程

- 10-9 我记得没错的话，我把非常复杂的GPIO的那一长串，第一次用define LED_ON（） 和 LED_OFF（） 表示，这样的话，调用起来方便。
- 10-11 自检程序里 LED 承担了“报第几个轮子”的职责（闪 1/2/3/4 对应四个轮子）——第一次把LED当作状态机
- 10-13 把灯态宏和LED闪烁函数集中到 `board.h` （说简单点，就是引入一个专门用来给LED小灯的头文件，里面放一些很好用的，也很常用的表示方式，比如，快闪，慢闪，常亮......等等常用设置）
- 10-19 22:48 并入 `tune.c` 的 `tune_led()`。
