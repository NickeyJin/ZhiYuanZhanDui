# 02 底盘与全向移动

底盘是整个项目里改动次数最多的部分：10-11 从零写出第一版、10-12 做出全向移动、10-19 又一次从零重构。本篇按时间顺序记录三次迭代。
（碎碎念：之所以让AI重构那么多次，实际上本来以为是自己的嵌入式的问题，导致轮子一直转的不平稳，改的越来越烦躁，就让AI返工重写。后面发现是买到劣质电机了，前后路相同电压输出的情况下，速度可以相差20%，而且，左后方的轮子电机内的阻力明显大于其他，可以说哪里都是问题，到文档最后看吧）

## 电机驱动与 PWM 时基（第一版）

### 功能描述

| 轮子 | 引脚 | 定时器 |
|---|---|---|
| 左前 FL | PA0 / PA1 | TIM2_CH1 / CH2 |
| 右前 FR | PA2 / PA3 | TIM2_CH3 / CH4 |
| 左后 RL | PB0 / PB1 | TIM3_CH3 / CH4 |
| 右后 RR | PA8 / PA11 | TIM1_CH1 / CH4 |

代码分四层、依赖单向：`app → chassis → motor`、`app → ps2`。
`motor.c` 只负责“某个轮子给多大速度”，`chassis.c` 负责麦轮逆解，`app.c` 负责读手柄和流程。

第一版 PWM 时基：**PSC=0 / ARR=3599 → 72MHz / 3600 = 20kHz**（3600 步，占空比分辨率 0.05%）。
当时对比过 PSC=71 / ARR=49（只有 50 步，不够精细）而否决。

### 开发历程

- 最初的版本“车子根本动都不会动”，于是把全车逻辑先放一边，写了一个上电自检。
- 自检种暴露了两个问题，靠“闪几下认定时第几个轮子”一点点定位：
  - 左后轮似乎有些问题和故障，运动不了了（现在想来，当时的确是因为阻力太大，轮子不转）
  - 纯粹的电压不够大，只要抬起来，其实就可以看到轮子在慢慢转。

## 底盘从零重构（第二版 PWM 时基与占空比）

### 功能描述

10-19 车上加了配重，底盘表现变差，四个轮子又双叒叕的不转了，于是抛弃所有旧配速、从零让AI重写（`chassis.c/h`、`motor.c/h`、`main.c`）。
（现在想想，其实也没有那么必要）

### 开发历程

在看到四个轮子都没有转的时候，我准备做一个实验，去探究一下，为什么会这样。

实验流程：
我是先测试了一下会不会是硬件的问题，用杜邦线直连5V档，发现4个轮子都没有问题，反过来也是一样的。
因此得知可能是PWM的问题，但是PWM的参数还挺多的，频率，占空比，电压等等，于是进一步一点点排查。

而后，我测试了一下20kHz，占空比80%；还有100Hz 40%。实测以上两种情况4个轮子又开始在地上运动。
根据结果，得出猜测：20kHz，占空比40%这一标准

- 可能要么是电压不够
- 要么是频率太高驱动板跟不上。

——进一步测试，观察到：
 20kHz 80% 的速度小于 100Hz 40%的速度小于 1kHz 80% 的速度

根据控制变量法得出结论：

我们使用的马达的启动电压要求比较高。
并且，可能是驱动板的问题，频率越快，有效占空比越小，电压越小。
并且，影响速度变化的大小的影响因子应当是电压 > 频率。

针对这两个问题，就有了以下的这个解决方案。（当时还没有意识到是电机的问题，所以想到了这个办法）

## 起步补偿（“踹一脚”——给一个瞬间的高电平）

### 功能描述

TT 电机静摩擦大，小占空比指令下不转。做法是在**起步瞬间**把占空比临时放大：

```c
MOTOR_KICK_MS   = 90     /* 起步补偿持续时间 */
MOTOR_KICK_GAIN = 200    /* 瞬间放大到 200%（仍钳在满速）  */
MOTOR_KICK_MIN  = 450    /* 指令小于 450 不补偿，避免轻推摇杆一顿一顿 */
```

通过这样的操作，从而能提供每个轮子一开始的一个起步电压。
坏处：在微操的时候，通常会猛冲一下，不过代价可以接受。

## 现场配速与整定（`tune` 旋钮）

### 功能描述

麦轮的纯横移混控是**四轮等幅**，一旦四个轮子的实际速度不一致，差值会投影成自转分量——表现就是“横移画圈”。

- **总速度**：四个轮子等比缩放，改的是快慢手感；
- **单轮补偿**：某个轮子单独加减，改的是“哪边偏”；
- **前后配平**：前一对 vs 后一对的差，改的是画圈的旋转分量。

最终输出：

```
PWM = 指令 × t_speed_scale/1000 × （1000 + 单轮补偿 + 前后配平 + 基准配速）/1000
```

### 开发历程

- 10-17 第一次现场配速（左右平移失效）：早期四轮基准 `900/880/1050/1000`，现场改成 `850/850/1100/1100`，稍微稳定了一点点。
- 10-17 14:06 定位“左右平移有问题”的重要原因之一——右后轮机械装反。（现在想来，还是觉得非常的好笑，我宁愿相信是自己的代码出错了，也不相信是接线的问题。最后我在自检的时候，发现，哎，第2个轮子不应该是右前嘛？怎么变成右后转了了。在和“硬件”进行“友好的沟通交流”之后，换了下线，好歹可以用了）
- 10-19 emm，这天直接熬到了第二天凌晨4:30，别问为什么，问就是为了调整我们这个神奇的劣质麦轮+电机，挑了半天还根本没有效果，以下是我发现的“巨量”问题里最重要的几个：
  - 左后轮有明显的凝滞感，就是电机的问题，电机内部摩擦力偏高不少。（这也能解释为什么我不断调整速度，发现前面一个刚调好，左移没有问题，稍微加点速就有问题了，这个就是物理公式了，P=Fv，速度变快，需要的功率更高了）
  - 左前轮的需要的起步电压比其他三个轮子都要来得高一点。（因为起步比别人来得更晚，因此呢，在左移，一开始就会少力。同时在直线运动的时候，也会因为这个，从而导致方向的偏移）
  - 除去上面这些问题，4个轮子输入相同电压时，明显转速不一致。（哪怕是看起来比较整齐的右轮）

## 底盘控制参数（现行）

| 参数 | 值 | 含义 |
|---|---|---|
| `APP_LOOP_MS` | 20 | 控制节拍 50Hz |
| `APP_SPEED_MAX` / `APP_SPEED_SLOW` / `APP_SPEED_MIN` | 800 / 400 / 250 | 平移速度上限 / 按住 L1 减半 / 最小可动速度 |
| `APP_TURN_MAX` / `APP_TURN_MIN` | 800 / 400 | 自转速度上限 / 下限（太低只嗡鸣不走） |
| `APP_RAMP_MS` | 250 | 斜坡时间（加减速不过冲） |
| `APP_STICK_DEADZONE` | 12 | 摇杆死区（PS2 中位 128） |
| `CHASSIS_SPEED_MAX` | 800 | 逆解后轮速上限（留叠加余量） |
| `MOTOR_PWM_PSC` / `ARR` | 71 / 49 | 1µs 步长、20kHz |
| `MOTOR_DUTY_PERCENT` | 80 | 满速占空比（40% 实测不动） |
| `MOTOR_KICK_MS` / `GAIN` / `MIN` | 90 / 200 / 450 | 起步补偿 |
