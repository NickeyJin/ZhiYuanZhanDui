## 2. 自研部分（声明为原创）

固件：`motor.c/h`、`chassis.c/h`、`ps2.c/h`、`app.c/h`、`board.h`、`tune.c/h`、`arm.c/h`、`dwt_delay.c/h`。

工具脚本：`build\tools\direct_build.ps1`、`flash.ps1`、`read_vars.ps1`。

## 3. 结论

**除 ST 官方 HAL / CMSIS / CubeMX 模板与 GNU 工具链外，本项目未引入任何第三方 C 库。**

PS2 手柄协议部分参考厂商手册自行实现（软件模拟时序，未使用硬件 SPI）；
麦轮逆运动学公式来自通用教材，代码中的量纲化简为本项目自行处理；
机械臂未使用实时逆解，姿态由现场标定后写成常量。
