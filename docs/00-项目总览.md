## 1. 机器人一句话描述

一台用 PS2 手柄遥控的全向移动小车：底盘四个 60mm 麦克纳姆轮由 3 片 DRV8833 驱动 4 个 TT 减速电机，
可以前后、左右平移和原地自转；车上一只四舵机机械臂（肩 / 肘 / 腕 / 夹爪）负责把 30mm 立方体
（能量单元）夹起并放进目标洞口，按一次 `R2+R1` 就能完成"回放块位 → 三轴到位 → 张爪丢块 → 回到原姿态"。

## 2. 设计约束（来自比赛规则）

| 约束 | 数值 | 对设计的影响 |
|---|---|---|
| 开局外形 | 高 ≤ 210mm | 机械臂必须能在开局收成平躺折叠姿态 |
| 运行中包络 | ≤ 445×400×450mm 或 φ550mm 球 | 臂展按"小臂 + 腕"分两段控制，不做大回转 |
| 整机重量 | ≤ 2.0kg | 机械臂选 MG995 + SG90 的轻量组合 |
| 抗跌落 | 150~200mm 自由落体不掉件 | 夹爪闭合位留 6mm 小孔靠摩擦夹持 |
| 成本 | 新生组不推荐超 400 元 | 结构件改现货、3D 打印件自制 |
| 断电 | 必须适配官方无线继电器（10m 内断电） | 列为收尾项 |
